# Stuck log

Every time something confuses you, breaks, or takes longer than expected, add a row.
Getting stuck is normal and it's how everyone learns this. Your log is useful for you (you'll
see how much you've figured out) and for class (we'll go over common ones together).

| Date | What I was trying to do | What went wrong | How I got unstuck | Time it took |
|---|---|---|---|---|
| | | | | |

**When you're stuck:** paste the error or describe what you see to Claude Code and ask:
*"Explain what's happening in simple terms, then help me fix it."*
